# SAMEER JI ALL ROUNDER BOT 🎓

Ek Telegram bot jo video leech karta hai aur tumhare channel me bhejta hai!

## 🛠 Features
- Batch-wise download
- Quality select (360p, 720p, etc.)
- Telegram channel me direct upload
- Koyeb deploy-ready

## 🚀 Deploy Steps
1. `git clone` karo repo
2. `.env` file me config set karo
3. `pip install -r requirements.txt`
4. `python main.py`

## ✅ Usage
`/video <link> <quality> <batch>`
